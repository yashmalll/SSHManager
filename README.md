Терминальный менеджер SSH-хостов на Python (`curses`). Один файл, без внешних зависимостей.

## Возможности

- Список хостов с цветными маркерами, карточкой деталей и поиском на лету
- Добавление, редактирование, копирование и удаление хостов
- Проброс портов: `-L` (локальный), `-R` (обратный), `-D` (SOCKS5), с включением и выключением
- Режим «только туннель» (`ssh -N`) без оболочки
- Импорт из `~/.ssh/config` и `~/.ssh/known_hosts` с выбором нужных хостов
- Подключение по Enter (запускается обычный `ssh`)

## Требования

- Python 3.8+ (используется только стандартная библиотека)
- Установленный `ssh` (OpenSSH)
- Терминал с Unicode. Для лучшего вида нужна поддержка 256 цветов.

## Запуск

```bash
git clone <repo> SSHManager && cd SSHManager
chmod +x sshm.py
./sshm.py
```

Хосты хранятся в `~/.config/sshmanager/hosts.json` (или в `$XDG_CONFIG_HOME/sshmanager/`).

## Запуск через alias

Чтобы запускать менеджер командой `kon` из любой папки, добавьте alias. Путь замените на свой.

**bash** (`~/.bashrc`) и **zsh** (`~/.zshrc`):

```bash
echo "alias kon='python3 /home/sshm.py'" >> ~/.bashrc
source ~/.bashrc
```

Для zsh вместо `~/.bashrc` используйте `~/.zshrc`.

**fish:**

```fish
alias --save kon 'python3 /home/SSHManager/sshm.py'
```

Команда `--save` сразу записывает функцию в `~/.config/fish/functions/`, перезапускать оболочку не нужно.

После этого достаточно набрать:

```bash
kon
```

> Если файл сделан исполняемым (`chmod +x sshm.py`), в alias можно указать только путь к нему, без `python3`.

Альтернатива без alias: положите ссылку в папку из `$PATH`.

```bash
ln -s /home/SSHManager/sshm.py ~/.local/bin/kon
```

## Управление

Внизу находится строка ввода. Текст в ней фильтрует список, а слово-команда с Enter выполняет действие.

| Клавиша | Действие |
|---|---|
| `↑` / `↓`, `PgUp` / `PgDn` | выбор хоста |
| `Enter` | подключиться (или выполнить команду из строки ввода) |
| `Ctrl+N` | новый хост |
| `Ctrl+E` | редактировать |
| `Ctrl+D`, `Del` на пустой строке | удалить |
| `Ctrl+K` | копировать |
| `Ctrl+F` | пробросы портов выбранного хоста |
| `Ctrl+T` | запустить только туннель (`Ctrl+C` — остановить) |
| `Ctrl+O` | импорт хостов с выбором |
| `Esc` | очистить ввод, на пустой строке — выход |
| `Ctrl+C` | выход |

Команды в строке ввода: `a` (add), `e` (edit), `c` (copy), `d` (del), `i` (import), `f` (forward), `t` (tunnel), `q` (quit). Перед командой можно поставить `:` или `/`.

> Если у хоста название совпадает с командой (например, `d` или `i`), Enter выполнит команду. Такой хост выбирайте стрелками при пустой строке.

### Форма хоста

Поля: название, хост, пользователь, порт, файл ключа, теги, доп. опции ssh. Перемещение между полями: `Tab` и `↑`/`↓`. `Ctrl+S` сохраняет, `Esc` отменяет.

### Проброс портов

| Тип | Что делает | Аргумент ssh |
|---|---|---|
| `L` | порт сервера становится доступен у вас | `-L порт:хост:порт` |
| `R` | ваш порт становится доступен на сервере | `-R порт:хост:порт` |
| `D` | SOCKS5-прокси на локальном порту | `-D порт` |

В окне пробросов (`Ctrl+F`): `Space` включает и выключает, `a` добавляет, `e` изменяет, `d` удаляет. Включённые пробросы добавляются при подключении по Enter и при запуске туннеля.

### Импорт

`Ctrl+O` показывает список хостов из `~/.ssh/config` и `known_hosts`. Уже добавленные хосты в список не попадают. `Space` отмечает, `a` отмечает все, `n` снимает отметки, `Enter` импортирует отмеченные, `Esc` отменяет. Записи с шаблонами (`*`, `?`) и хешированные записи `known_hosts` пропускаются.
